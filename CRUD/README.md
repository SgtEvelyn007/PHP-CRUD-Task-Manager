# PHP MySQL CRUD Application

## Project Structure
- `index.php` - Main page (Read operations)
- `create.php` - Create new records
- `update.php` - Update existing records
- `delete.php` - Delete records
- `config/database.php` - Database configuration
- `sql/database.sql` - Database schema

## Setup Instructions
1. Import `sql/database.sql` to phpMyAdmin
2. Update database credentials in `config/database.php`
3. Access application at `http://localhost/CRUD/`
